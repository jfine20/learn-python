# Learn Python — What Things Actually Mean

Each module has:
- `notes.md` — the concept explained deeply, not just "here's the syntax"
- `exercise.py` — exercises with `TODO` comments
- `solution.py` — solutions with explanations

## Modules

| # | Topic | Core idea |
|---|-------|-----------|
| 01 | Variables & Types | A variable is a *name tag*, not a box |
| 02 | Control Flow | How Python decides what's true |
| 03 | Functions | Functions are objects — what that means |
| 04 | Lists & Loops | How iteration actually works |
| 05 | Dicts & Sets | Hash tables — why lookups are instant |
| 06 | Classes & Objects | What `self` really is |
| 07 | Error Handling | Exceptions as control flow |
| 08 | Modules | How `import` actually works |

## How to use this

Work through modules in order. In each `exercise.py`, fill in the `TODO` sections and run the file:

```bash
python 01_variables_and_types/exercise.py
```

Don't peek at `solution.py` until you've tried.
